Helm AI es una app de outfits y chat con IA: Look Lab, Studio, armario y shop.

Este repo es el **mostrador público** de los APK que usan las testers. El código vive en repos privados.

## Instalar

1. Entrá a **[Releases](https://github.com/alexcautivo/helm-ai-apk/releases/latest)** y bajá `helm-ai-*-https.apk`.
2. En el teléfono: **Ajustes → Seguridad** (o la app con la que lo abriste) → permitir **instalar apps desconocidas**.
3. Abrí el archivo y tocá **Instalar**.
4. Entrá con **Google** o con mail y contraseña.

Si ya tenías una versión anterior, instalá encima: se conservan la cuenta y los chats.

## Qué probar

- Crear cuenta y abrir Ajustes → Cuenta
- Recuperar cuenta con un código de 6 dígitos (si olvidas la contraseña)
- Un look / try-on con **tu** foto (del teléfono o de Media)
- Chat y un agente
- Shop: una prenda debería abrir la app SHEIN si la tenés instalada
- Ajustes → Novedades, Reportar error y Sugerir funcionalidad
- Cambiar el aspecto y mirar la tira LED (si hay avisos) entre el plan y los looks
- Si algo falla, copiá el **código** del aviso y mandalo

## Qué no es esto

- No es la ficha de Play Store
- No hay Windows ni iOS en este repo
- No hay código, keys ni base de datos
